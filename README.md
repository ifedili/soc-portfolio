# SOC Analyst Portfolio — Ifediora Okolo

A dark-themed cybersecurity portfolio built with React + Vite.

## Getting Started

```bash
npm install
npm run dev
```

## Sections

- **About** — Introduction and background
- **Skills & Certifications** — Tools, frameworks, and credentials
- **Featured Projects** — Hands-on labs and tools with browser mockup cards
- **Playbooks** — Expandable incident response playbooks with step-by-step procedures
- **IR Reports** — Detailed incident case files with timelines, IOCs, and MITRE mappings
- **Articles** — Cybersecurity blog posts and write-ups
- **Contact** — Email, LinkedIn, GitHub links

## Customization

Edit the data arrays at the top of `src/App.jsx` to update your personal info, projects, playbooks, and reports.

## Build for Production

```bash
npm run build
```

Output will be in the `dist/` folder.
